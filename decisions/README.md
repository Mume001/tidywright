# Dnevnik odluka

Jedna odluka, jedan fajl. Format:

```
# 000X Naslov odluke

Datum:
Status: prihvaćeno | zamijenjeno odlukom 000Y

## Kontekst
Šta je bilo pitanje.

## Odluka
Šta smo odlučili, u jednoj rečenici.

## Zašto
Razlozi, s brojkama gdje postoje.

## Posljedice
Šta ovo znači za proizvod, kod i cijenu.
```

Odluka koja je ovdje zapisana se ne raspravlja ponovo dok je neko izričito ne otvori.
Ako se promijeni, stari fajl ostaje i dobija status "zamijenjeno".

| 0002 | Ne kupujemo tuđe podatke |
| 0003 | Ništa se ne primjenjuje bez odobrenja čovjeka |
| 0004 | Prvi kanal je ugradbeni widget |
| 0005 | Opseg prve verzije widgeta |
| 0006 | Stack |
| 0007 | Ime i domene |
