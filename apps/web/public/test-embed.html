Test page, not part of the product

Served from apps/web/public/test-embed.html. It exists so the embed can be tried the way an agency will use it, and so every state of the report can be opened without waiting for one to happen.

The tag an agency pastes

<script src="https://siteauditserver.com/embed.js" data-key="pk_live_..." async></script>
<div id="tw-audit"></div>

Test it cross origin, which is the case that actually matters

Opened from localhost:3000 this page is same origin with the app, and an embed that only works there is an embed that breaks at the first agency. Serve this file from a different port and load it there: 

python3 -m http.server 4000 --directory apps/web/public
# or: npx serve apps/web/public -p 4000
# then open http://localhost:4000/test-embed.html

The script tag below points at http://localhost:3000 on purpose, so the iframe, the resize messages and the report link are all crossing an origin boundary.

On a phone

Run pnpm dev, find your machine's address on the network, and open http://<address>:3000/test-embed.html. The form and the report both have to work at 360 px.
